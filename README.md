# CAPSTONE 67 — AI Storytelling and Creative Writing Lab

## Project Title
The Library of Forgotten Stars

## Genre
Fantasy Mystery

## Project Description
Nila, an eighteen-year-old girl, discovers a secret magical library beneath an abandoned clock tower. Its books contain forgotten memories, and stars are mysteriously disappearing from the sky.

## Objectives
- Use AI for story brainstorming and character development.
- Develop a fantasy mystery story.
- Improve AI-generated writing through human editing.
- Explore the ethical use of AI.

## Technologies Used
- HTML
- CSS
- JavaScript
- AI writing and image-generation tools

## Interactive Demo
The index.html file contains an interactive version of the story with choices.

## Conclusion
This project demonstrates how AI can support human creativity without replacing the writer.
